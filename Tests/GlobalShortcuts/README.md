# 全局快捷键注册验证

在 macOS 桌面会话中执行 `Tests/GlobalShortcuts/run.sh`。

只临时注册 Control+Option+Shift+F9/F10/F11/F12，构造但不投递按键事件，不读写剪贴板、不调用 FTP。组合被用户其他程序占用时测试会失败，请不要为测试关闭用户软件。

覆盖：复制/粘贴完整 Command 按下与释放事件的顺序、键码、flags、marker 和 combined session source；AX 菜单元数据的字符优先、虚拟键回退、Command 修饰位、禁用/不支持/歧义、超时禁止重试；显式复制发送的纯判定（已确认分发、保护窗口内延迟更新的 changeCount、粘贴排除、缺少基线、取消/目标变化、新物理操作优先阻断、超时、无确认键盘回退不发送）；成对注册、复制/粘贴组合交换复用、第二键冲突时回滚新注册且保留旧配置、录键暂停与恢复、stop释放、禁用跨录键恢复、对象销毁释放。共 10 项检查。

仅本地 responder 确认处理或 AX 菜单成功返回后，允许最长 1 秒、25 毫秒间隔的 HID 保护窗口等待应用延迟写入剪贴板。请求、松键、分发和每轮确认期间 HID 指纹必须保持不变；新物理操作优先于 changeCount 变化取消发送。HID 指纹只含 keyDown、mouseDown 与滚轮计数，不读取按键内容，并排除正常松键的 keyUp/flags。回调前再次检查输入、目标、取消/录制状态和单调时钟期限，再在同一 MainActor 时段同步回调。保护窗口并不接受后续任意剪贴板变化；键盘回退缺少执行确认时始终不发送。回调携带观察到的 changeCount，接收方仍须在读取前后核对计数并冻结内容。探针用合成计数验证策略，不读取系统剪贴板。

这个探针验证注册生命周期；实际跨应用复制/粘贴必须由用户允许系统辅助功能权限后再做界面验收。
