# 全局快捷键注册验证

在 macOS 桌面会话中执行 `Tests/GlobalShortcuts/run.sh`。

CI 使用 `Tests/GlobalShortcuts/run.sh --resource-smoke`，只验证原生工具的编译、链接和临时目录中的双语资源加载；不创建应用、不注册快捷键、不投递事件、不访问剪贴板或 FTP。

脚本通过 `swift build --show-bin-path` 定位当前构建产物，兼容模块在产物根目录或 `Modules` 子目录的布局；优先链接 `libCopyToolCore.a`，否则链接 SwiftPM 的 `CopyToolCore.build` 目标文件。编译会同时带入快捷键服务和 `ShortcutInputGuard.swift`，并将本次构建的 `CopyTool_CopyToolCore.bundle` 复制到临时探针旁，避免语言资源缺失导致退出。临时程序、资源与模块缓存会在结束时清理。

只临时注册 Control+Option+Shift+F9/F10/F11/F12，构造但不投递按键事件，不读写剪贴板、不调用 FTP。组合被用户其他程序占用时测试会失败，请不要为测试关闭用户软件。

覆盖：复制/粘贴完整 Command 按下与释放事件的顺序、键码、flags、marker 和 combined session source；AX 菜单元数据的字符优先、虚拟键回退、Command 修饰位、禁用/不支持/歧义、超时禁止重试；显式复制发送的纯判定（已确认分发、保护窗口内延迟更新的 changeCount、粘贴排除、缺少基线、取消/目标变化、新物理操作优先阻断、超时、仅投递按键但无剪贴板更新时不发送）；成对注册、复制/粘贴组合交换复用、第二键冲突时回滚新注册且保留旧配置、录键暂停与恢复、stop释放、禁用跨录键恢复、对象销毁释放。共 12 项检查（含松键单次触发、重复释放去重及原目标保留）。

快捷键在释放时提交一次，保留按下时的前台应用，并继续等待配置的主键与 Command、Option、Control、Shift、Fn 全部松开。Carbon 的组合释放通知不能单独证明主键已松开。后续新的 Carbon 热键按下或本应用非重复热键按下会取消当前请求，不能覆盖原请求的目标或输入基线。

每次显式复制／粘贴请求只在执行期间建立输入保护。目标是外部应用时，使用短期 `cgSessionEventTap`／`defaultTap`，在独立线程的回调内同步更新 generation；回调始终原样返回事件，不修改或截断输入。本应用内使用同步 local monitor。保护仅检查 keyDown、mouseDown、滚轮的事件类型、时间戳和本应用合成标记，不读取或保存键值、文本内容或事件对象；正常 keyUp／修饰键释放不增加 generation。本应用自己生成的 Command+C/V 通过标记排除。请求从 generation 0 开始，启动观察期间也不能重新设置基线。无法建立保护、保护失效、权限丢失或观察中断时停止本次操作；请求结束立即拆除观察，另有独立生命周期上限。

菜单读取失败或扫描不完整、尚未执行 AX 动作时允许按键回退；AX 动作执行结果不确定时仍禁止重试。复制命令分发后，允许最长 1 秒、25 毫秒间隔等待应用写入剪贴板。从等待松键、菜单分发、按键回退，到每轮复制确认，始终核对同一个输入 generation；任何新的受保护输入优先于 changeCount 变化取消发送。CoreGraphics 的累积事件计数只保留作时序诊断，不再作为复制或发送授权依据。

回调前再次检查输入保护、目标、取消／录制状态和单调时钟期限，再在同一 MainActor 时段同步回调。按键回退必须观察到保护窗口内的新剪贴板计数才能发送，仅投递按键不会发送。回调携带观察到的 changeCount，接收方仍须在读取前后核对计数并冻结内容。注册探针使用合成状态验证策略，不读取系统剪贴板；输入保护策略的单元测试验证事件分类、标记排除、旧事件排除、generation 变化、观察失效和取消。

这个探针验证注册生命周期；实际跨应用复制/粘贴必须由用户允许系统辅助功能权限后再做界面验收。

IDEA（Ultimate/Community）直接使用标准 Command+C/V，跳过 Java 菜单扫描；复制仍要求保护窗口内的剪贴板计数更新，访达等应用保留 AX 菜单路径。
