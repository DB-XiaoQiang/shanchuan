# FTP 连接测试验证

在项目根目录运行：

```sh
python3 Tests/FTPConnection/mock_ftp.py
```

只绑定 `127.0.0.1` 的临时端口，使用合成用户名、密码和中文目录，不读取用户设置或钥匙串，不连接真实 FTP。

系统 curl 通过标准输入接收凭据、根目录 URL 和 `CWD` 命令，使用 `--head` 避免建立数据连接；连接超时 8 秒，总超时 15 秒。独立的测试实例只终止自己的 curl 进程。成功仅表示 FTP 登录与配置目标目录访问成功，不能据此声称具有上传权限或内网接收成功。

验证包括：登录及中文带空格目录、引号与反斜杠凭据、认证失败、目录拒绝、端口关闭、登录阶段连接超时、认证后目录命令总超时、运行中取消、启动前取消、取消后另一实例正常连接。服务器故意在错误中回显合成凭据，客户端只呈现本地错误分类，不转发服务器原文。测试检查 curl 参数中没有动态配置，也检查服务器仅收到 `USER`、`PASS`、`PWD`、`CWD`、`QUIT`，没有 `STOR`、`MKD`、`DELE`、目录列表或数据通道命令。

实现依据：[curl 官方手册的 --head、--quote、--config 和超时选项](https://curl.se/docs/manpage.html)。
