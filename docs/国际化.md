# 简体中文与英文

macOS 和 Windows 支持简体中文（`zh-Hans`）与英文（`en`）。应用默认使用简体中文，不跟随系统自动切换；旧配置缺少语言项或语言值无效时也使用简体中文。

在配置中心选择语言后，需要正常退出并重新打开应用。这样主界面、菜单、应用内提示及更新窗口使用同一语言，避免正在进行的传输或安装流程中途改变文字。正式闪传与独立更新测试应用分别保存自己的语言偏好。

## macOS 资源与更新窗口

应用文案位于 `Sources/CopyToolCore/Resources/zh-Hans.lproj/Localizable.strings` 和 `en.lproj/Localizable.strings`。中文原文是稳定资源键；带参数的消息使用格式字符串，协议常量、远端路径、文件名、账号、用户内容以及旧历史记录不作翻译。

`L10n` 在创建 SwiftUI/AppKit 场景之前确定应用专属语言，并设置当前应用偏好域的 `AppleLanguages`。本应用不修改系统语言或其他应用的语言设置。两种语言的资源键必须完整对应。

打包时，`stage-localizations.py` 将 SwiftPM 的 `CopyTool_CopyToolCore.bundle` 放入 `Contents/Resources`，并声明 `CFBundleDevelopmentRegion=zh-Hans`、`CFBundleLocalizations=[zh-Hans,en]`。宿主 `InfoPlist.strings` 同时提供“闪传 / Shanchuan”和“闪传更新测试 / Shanchuan Update Test”的名称，让 Sparkle 标题读取所选语言的应用名称，Bundle ID 保持不变。语言资源须在代码签名前放入包内；签名后再修改文字会破坏应用签名。

截图中的 “Updating …”“Ready to Install”“Install and Relaunch” 属于宿主进程内的 Sparkle 标准界面。Sparkle 2.10.1 已提供这些简体中文译文，应用现在通过宿主语言声明和最早的语言初始化来选择它们：默认会显示“正在更新…”“可以开始安装了”“安装并重启应用”。选择英文并重启后，Sparkle 同样使用英文。

SDK 2.10.1 的官方简体中文表另有五条新增提示缺失，包括更新信息/更新说明签名错误、更新说明下载失败和两条设备兼容提示。打包工具只在待签名的应用副本中补齐这些键；保留所有现有 SDK 译文，未来 SDK 提供官方中文时优先保留官方值。不修改已安装的框架，不删除其他语言或修改第三方辅助程序的标识。

语言控制有两个外部边界：

- 主应用退出后短暂出现的 Sparkle `Updater.app` 安装进度是独立进程；当前 SDK 不传递宿主应用的语言偏好，它仍按照系统语言选择文案。本项目不写入它的共享偏好域，以免改变其他使用 Sparkle 的应用。
- macOS 的系统授权、账户密码和系统错误界面由系统及 SDK 决定。Sparkle 的管理员授权说明在 SDK 中还存在未本地化的英文文案；应用不能把这些系统窗口保证为应用所选语言。

以上边界不影响截图中宿主更新弹框的中文化，但不能把宿主文案验证当作所有外部安装窗口的完整语言验收。

## Windows 资源与语言保存

Windows 资源位于 `windows/src/Shanchuan.Core/Localization/zh-Hans.json` 和 `en.json`，由 `Localization` 统一读取。语言保存在配置的 `language` 字段；兼容旧配置，克隆和保存配置时保留语言值。启动时在 WPF 窗口、托盘和更新提示创建之前设置应用文化。

XAML 与应用生成的消息使用同一资源表。更新确认采用应用自己的窗口，按钮也随语言切换：中文为“更新并重启／稍后”，英文为“Update and restart／Later”。默认选择稍后，关闭或按 Escape 不会批准安装。系统文件选择器、系统权限及服务器返回的原始内容保留相应系统或来源的语言。

历史状态和筛选项的内部值保持稳定，只在界面显示时翻译；不把翻译后的文字用作网络模式、权限判断或协议字段。现有日志保留其生成时的语言。

## 验证

发布工具测试覆盖资源缺失、两语言键不一致、重复键、格式参数一致性、源代码所有显式本地化键覆盖、英文残留中文、SwiftPM 结构式资源包，以及 Sparkle 关键中文资源缺失时停止打包。

```sh
python3 -m unittest discover -s Tests/Release -p 'test_localization_packaging.py'
python3 scripts/verify-sparkle-localization.py
python3 scripts/verify-sparkle-localization.py --app "dist/闪传.app"
```

后两条命令编译并运行临时的纯命令行探针，分别在新进程中验证默认简体中文、显式简体中文及英文，复用真实 `L10n` 启动逻辑并读取 Core 及 Sparkle 的实际资源，包括截图三条文案和完整 SDK 中文表；不会创建 GUI、发起更新或安装软件。探针使用独立临时偏好域，结束时移除，不读取或更改已安装应用的配置。`--app` 同时验证已打包应用的语言声明、本地化应用名称、嵌入资源与五条补充错误提示。双端构建与版本发布的 macOS 打包阶段都会运行这一验证。

实际安装重启的语言体验仍需在测试应用中验收。语言修改不自动递增产品版本，也不覆盖已公开的发行附件。
