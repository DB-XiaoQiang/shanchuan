# 闪传 v0.1.4（预发布）

版本号由用户指定为 0.1.4，发布通道保持公开预发布，正式自动更新继续关闭。

- macOS 与 Windows 的目录排除规则新增“展开编辑…”入口，使用可调整大小的独立大编辑框。
- 提供等宽字体和横纵滚动，长路径不折行，长规则列表可完整查看和编辑。
- 沿用配置自动保存；“完成”提交最后输入后关闭，错误规则显示行号并保留上次有效配置。
- 保留常用规则入口、注释、原规则文本及匹配方式，无需迁移配置文件。

配置中心本身继续使用主窗口中的独立页面。本预发布不生成稳定更新清单，现有客户端不会自动发现或安装此测试版。请使用 Setup / DMG 手动升级；macOS 正式签名、公证仍待配置。
