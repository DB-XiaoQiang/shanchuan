# 闪传 0.2.2：修复 macOS 快捷键复制被误取消

- 修复在 IntelliJ IDEA 等应用中完整按下、松开复制快捷键后，仍提示“等待快捷键释放期间检测到新的操作，未发送”的问题。
- macOS 不再使用可能延后的系统累计按键统计判断本次复制是否被后续操作打断，改为只在本次显式操作期间建立输入保护。
- 快捷键首次按下时建立保护，松开时复用同一次请求；主键和修饰键全部松开后才执行复制，长按重复不会重复发送。
- 保留新按键、点击、滚动、前台应用切换、权限失效及超时的取消检查；复制成功仍须确认剪贴板确实更新。
- 输入保护不记录键码、输入字符或剪贴板内容，结束后立即释放；无需新增系统权限。

本次功能修复位于 macOS；Windows 随统一版本重新构建。

本版本为公开预发布，仅供下载测试。正式自动更新通道继续关闭。macOS 使用现有 Apple Development 身份签名，尚未进行 Developer ID 签名及 Apple 公证；Windows 安装包尚无 Authenticode 签名。
