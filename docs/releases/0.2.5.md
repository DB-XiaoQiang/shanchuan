# 闪传 0.2.5：精简更新入口与流程

- macOS、Windows 移除“下载测试版”入口及手动下载测试版的引导文案。
- 左下角采用紧凑更新状态区，每个阶段保留一个主操作：检查更新、失败重试或更新并重启。
- 下载阶段展示真实进度和字节数，全部附件校验完成后才显示安装入口。
- 检查时间、完整错误和 FTP 投递状态收进“更新详情”；展开后限制高度并支持滚动。更新就绪时仍可在详情中重新检查。
- 保留点击后才授权安装、固定版本验签及等待传输结束后重启的行为。
- 新增文案同步支持简体中文与英文，切换语言立即生效。

本版本继续使用未公证正式更新通道。macOS 安装包有稳定代码签名、Sparkle 更新签名和发行清单签名，尚未经过 Apple 公证；Windows 安装包尚无 Authenticode 签名。

新界面随本版本安装生效；旧版下载本版本时仍使用旧界面。
