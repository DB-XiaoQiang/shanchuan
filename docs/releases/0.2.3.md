# 闪传 0.2.3：开放未公证版本的在线更新

- 开放普通应用的在线更新源：每天本机时间 01:00 检查，发现版本后下载、验签并缓存，由用户点击确认安装。
- 统一 macOS 构建号的递增规则，旧版可以正确识别新构建；保留 0.2.2 的 IDEA 快捷键复制修复。
- 更新包附带 Sparkle 签名、发行清单签名和文件校验；传输未完成时等待，安装后保留配置和历史。

这是未公证的公开发行：macOS 使用现有稳定 Apple Development 身份签名，尚未通过 Apple 公证；首次安装可能需要在系统设置中明确允许。Windows 安装包尚无 Authenticode 签名。

0.2.2 保持原预发布及附件。此次使用新版本发布更新清单和固定版本 appcast，不覆盖旧安装包。
