# 闪传 0.2.1：语言切换立即生效

- macOS 与 Windows 在配置中心选择简体中文或 English 后，原窗口立即刷新，无需退出应用。
- 界面、菜单、当前状态和后续弹框跟随所选语言，语言偏好自动保存。
- 保留配置草稿、排除规则编辑、筛选和选择，不通过重新创建应用或重启 FTP、快捷键服务实现切换。
- macOS 使用 Sparkle 公开接口呈现更新窗口，解决原标准界面缓存旧语言的问题；下载、验签、替换和重启仍由 Sparkle 处理。

已经打开的应用内更新窗口也能刷新语言，切换本身不会批准安装或重新发起更新。历史日志、用户内容和协议值保持原样；系统授权及独立安装辅助窗口由系统或更新组件决定语言。

本版本为公开预发布，仅供下载测试。正式自动更新通道继续关闭。
