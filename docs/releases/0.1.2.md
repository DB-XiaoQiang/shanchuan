# 闪传 v0.1.2（预发布）

版本号由用户指定为 0.1.2，发布通道保持公开预发布，正式自动更新继续关闭。

- macOS 与 Windows 配置中心均改为主窗口内的独立导航页面，不再另开配置弹框。
- 保留原有配置自动保存、密码存储、快捷键录制、目录排除和传输设置；离开页面时处理未保存或无效输入。
- 增加隔离 Windows 环境的实际页面加载与原生更新安装、替换及重启验收。

本预发布仍不生成稳定更新清单，现有 0.1.1 客户端不会自动发现 0.1.2 预发布。更新引擎验收使用隔离测试实例和本地签名更新源，不访问公司 FTP，也不更改真实用户配置。公开测试安装请使用 Setup 或 DMG；正式签名公证仍待配置。
