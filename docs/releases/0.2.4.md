# 闪传 0.2.4：下载进度与一键更新

- macOS、Windows 左下角新增更新下载进度条，显示百分比、已下载大小和总大小；区分检查、下载与校验阶段。
- 已验证的缓存文件计入完成进度；全部更新附件和索引验证通过后才显示可安装状态。
- 下载完成后可查看目标版本及更新说明，点击“更新并重启”即授权本次更新，等待普通传输和更新转发结束后安装。
- macOS 保留 Sparkle 下载、验签、系统授权和应用替换流程；仅在明确点击后自动通过本轮已确认版本的应用内重复提示。
- 下载期间禁用旧候选安装入口，防止装错版本；失败和迟到的进度回调不会生成安装授权。
- 新增文案支持简体中文与英文，切换语言立即生效。

本版本继续作为未公证的正式更新发行。macOS 使用现有稳定代码签名身份和 Sparkle 更新签名，尚未通过 Apple 公证；系统可能要求明确允许。Windows 安装包尚无 Authenticode 签名。

新增进度界面随本版本安装生效，旧版本下载本版本时仍使用旧界面。macOS 点击更新后，Sparkle 可能再次下载 ZIP，并显示自己的安装进度。
