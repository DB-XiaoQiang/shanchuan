# 闪传 0.2.0：简体中文与英文

- macOS 与 Windows 新增双语界面，默认使用简体中文，不随系统语言自动切换。可在配置中心选择 English，正常退出并重新打开后生效。
- 主界面、配置、目录排除规则、进度提示、托盘/菜单、应用生成的错误及更新确认均接入语言资源。
- macOS 修复 Sparkle 更新弹框显示英文的问题，简体中文下显示“正在更新”“可以开始安装了”“安装并重启应用”；补齐更新组件缺失的中文错误提示。
- Windows 更新确认使用应用自己的本地化弹框，中文按钮为“更新并重启／稍后”；关闭或稍后不会批准安装。
- 英文界面调整了按钮与说明的布局，长说明可折行。

语言资源在应用签名前加入并校验，保留原有配置、历史状态、FTP 协议及凭据标识。旧配置缺少语言字段时默认简体中文。历史日志与服务器返回的原始内容保持原样；系统授权和外部安装辅助界面仍按系统或 SDK 选择语言。

本版本作为公开预发布供手动下载测试。正式自动更新通道继续关闭；macOS 正式 Developer ID 签名、公证及正式更新验收待后续配置。
