# 闪传 v0.1.3（预发布）

版本号由用户指定为 0.1.3，发布通道保持公开预发布，正式自动更新继续关闭。

- 修复手动“检查更新”缺少反馈的问题：两端显示检查结果和完成时间，反复检查也有明确反馈。
- 只有预发布、暂无正式更新时，说明测试版需要手动下载，并提供官方测试版下载入口。
- macOS 从应用菜单检查更新时显示主窗口；补充手动检查开始和完成日志，以及可读的 HTTP 错误提示。
- 修正检查按钮与等待安装状态的条件，避免按钮可点击却直接忽略操作。

本预发布不生成稳定更新清单，现有客户端不会自动发现或安装此测试版。请使用 Setup / DMG 手动升级；macOS 正式签名、公证仍待配置。FTP 检查频率、普通传输及文件清理策略沿用原设置。
