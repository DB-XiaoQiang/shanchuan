# 闪传 v0.3.0

- 每天本机时间 01:00 检查正式版本，启动和唤醒后补查。
- 左下角显示当前版本、更新状态及安装入口；后台不弹窗，确认后才安装。
- macOS / Windows 外网端独立下载 Windows 完整更新包，并通过专用 FTP 通道转发给同目录内网 Windows。
- 内网多台电脑独立只读收取更新，不占用剪贴板、不产生普通历史、不删除共享更新包。
- 更新采用发行清单签名和包 SHA-256 双重验证；安装等待普通传输与更新投递完成。

首次请手动安装本版本：Windows 使用 Setup，macOS 使用 DMG。内网自动更新需外网电脑先将同版本签名更新包投递至同一 FTP 目录。正式签名、公证和发行签名未满足时仅生成草稿，不进入客户端正式更新通道。
