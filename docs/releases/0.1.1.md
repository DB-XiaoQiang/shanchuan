# 闪传 v0.1.1（预发布）

本次版本号由用户指定为 0.1.1。此版本仅供手动下载测试，正式自动更新保持关闭。

- macOS 提供 DMG 拖拽安装包；Windows 提供 Setup 安装版和便携包。
- 左下角显示实际版本和更新状态。
- 包含每天 01:00 检查、启动/唤醒补查、签名校验、外网转发 Windows 更新至内网及用户确认后安装的实现，供后续正式通道上线验收。
- 本预发布不生成稳定更新清单，不会被正式更新检查发现，也不会自动转发测试更新包。

macOS 尚未配置 Developer ID 签名公证，Windows 安装包尚无 Authenticode 签名。请先等待传输结束并退出旧版，再手动安装。首次测试建议保留现有配置和安装包；安装后的系统权限与真实传输结果需在目标电脑验证。
